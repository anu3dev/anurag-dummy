# anurag-dummy

Dummy TypeScript application for testing the **AI Merge Conflict Resolver**.

## Structure

```
src/
  index.ts            - Entry point
  config.ts           - App configuration
  utils/
    greeting.ts       - Greeting utilities
    math.ts           - Math operations
  services/
    userService.ts    - User CRUD service
    logger.ts         - Logging service
```

## Purpose

This repo exists solely for raising test PRs with intentional file changes and conflicts, used by the AI Merge Conflict Resolver tool on [anuragkr.in](https://anuragkr.in).
